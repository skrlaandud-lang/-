# 작업기억판 1차 타입

기획서 요구사항을 빠르게 검증하기 위한 **React + TypeScript 기반 로컬 UI 프로토타입**입니다.

## 포함한 범위

- 상단 컨트롤(검색, 광고/건설 전환, 폴더 선택, 스캔 버튼)
- 실제 폴더 업로드(`<input webkitdirectory>`) 기반 파일명 재스캔
- 의뢰명 그룹화 + 광고/건설 혼합 데이터 자동 분류
- 규칙별 6개 점 + 점별 매칭 파일 설명
- 상태 요약(대기/진행중/완료)

## 실행

```bash
npm install
npm run dev
```

## 메모

브라우저 보안상 절대 경로를 직접 읽지는 못하므로, 프로토타입에서는 폴더 업로드 방식으로 파일명을 가져옵니다.
